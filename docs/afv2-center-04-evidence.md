# AFV2-CENTER-04 evidence

## Routed scope

[Node PR 115](https://github.com/ArcForges/ArcForges/pull/115) and [Cloud PR 169](https://github.com/ArcForges/Cloud/pull/169) add the published output, event, and resource watches and seven single-file transfer methods to the enrolled V2 channel. The private signed capability is `center-stream-data-v2`. Existing control-only peers keep their published behavior and refuse these new selectors before a send claim. Only WriteImport requests and ReadExport replies can exceed the general 1 MiB typed-body limit. Their typed-body limit is 2 MiB and the maximum private wire frame is 2 MiB plus 512 bytes. This carries a complete 1 MiB file chunk with its metadata. Output has a 64 KiB typed frame limit.

Each public watch pulls one authenticated frame at a time. The Center rechecks the viewer and entitlement before polling and before forwarding a frame. Node verifies the active channel, grant revision, and owned target. Resource watches expose complete snapshots and preserve their sample epoch and sequence. Admission rejects viewers beyond the per-account and Node limit. A separate per-frame write deadline bounds a stalled response writer. Output reconnect uses the original Run epoch and byte offset. Scoped event gaps come from durable SQLite cursors. Node migration 0019 adds those events on the same transaction as the matching Sandbox and Run changes. The previous SQLite migrations and the current PostgreSQL schema remain byte-identical to their baselines.

Transfer calls use the original Sandbox, owner epoch, actor, enrollment, grant, and revision. InspectTransfer observes the original durable transfer after a lost reply. The Center keeps the scoped receipt and effect metadata. The private file, staging data, and final snapshot remain on Node. The reviewed closed V2 route table keeps terminal writer, input and resize local. It excludes generic host-file, editor, search and workspace operations and V1 relay fallback. [Plan PR 230](https://github.com/ArcForges/Plan/pull/230) records the V2 retirement boundary and the finite V1 compatibility window. MIG-01 owns final global retirement after the consumer cutover.
