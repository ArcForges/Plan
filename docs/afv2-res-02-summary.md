# AFV2-RES-02 · Native Run limits

The Node keeps an owned Run's native CPU, memory and process limits tied to its original Windows Job or Linux cgroup. A Start records its concurrent hard grants before the supervisor may release the workload. Run policy revisions retain desired values, successful native settings, separate readback and the latest result for each dimension. The fixed official MXC 1.0.1 ProcessContainer and Bubblewrap executors remain in use.
