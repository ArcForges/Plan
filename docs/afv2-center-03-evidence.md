# AFV2-CENTER-03 evidence

## Remote control scope

[Node PR 114](https://github.com/ArcForges/ArcForges/pull/114) and [Cloud PR 168](https://github.com/ArcForges/Cloud/pull/168) connect thirteen typed unary operations to the existing owner-local Sandbox Core. The enrolled V2 relay negotiates the control channel separately and signs the exact call and result. Node rechecks its active channel and live local grant before admitting an effect. Go Center reserves the command in PostgreSQL and commits the send claim before transmission. Reconciliation keeps the original owner epoch, command, actor, target, enrollment, and grant revision. Center stores effect and routing metadata. The original result and private Sandbox data reside on Node.

A possibly delivered command can be observed through `NodeService.GetOperation` after the connection is replaced. An intact verified terminal result is available in that typed operation response, including as a status detail on a matching duplicate mutation. A compacted receipt reports its original effect and aggregate with the published `receipt_compacted` error. An offline relay cannot confirm the result of an earlier claim. A terminal Run can accept a new Stop command and complete it without an additional effect. The Cloud adapter preserves that signed Core outcome and limits the generated-shape compatibility to the exact Stop operation.

The existing Node receipt schema adds migration 0018. The PostgreSQL schema adds migration 0014. Existing migration bytes, archive inventories, and historical publication records remain available. [Plan PR 222](https://github.com/ArcForges/Plan/pull/222) scoped the exact Core, fixture, and provenance paths. [Plan PR 223](https://github.com/ArcForges/Plan/pull/223) scoped the existing account-cleanup admission and transaction-role audit. Both Plan changes had exact independent review and passed five stock checks on each designated host.
