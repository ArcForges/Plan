## Untested coverage and known limits

- **Reviewer's residual lows.** Step 5 evaluates only the last extension of a multi-extension chain. The lease holder is the last agent or extension, and no test distinguishes first from last (surviving mutants of that choice). Both are stated limits, not proven behavior.
- **Unauthenticated inputs.** `IssueAsync` takes the issuing chain and `RevokeAsync` the revoking principal as given; the host calls them only after its own decision and authentication (README and XML docs).
- **Task and risk at use.** A lease use names no task, so a lease ends with its task only if the host calls `EndTaskAsync` (otherwise at expiry); the stored effective risk is audit evidence and is not compared at use. A lease is not bound to a device or origin beyond the delegator's grant constraints, which still apply at every use.
- **Store failure.** `RevokeAsync` propagates a store exception instead of a typed failure (nothing is recorded, so it fails closed).
- **Time.** After a restart only the wall clock exists; the monotonic anchor is per manager instance.
- **Durable store.** Production Security stays Foundation-only; the durable lease store, event sink, ceiling source and trust fact sources are the host's. `SqliteStore` has no enumeration, so the test-only adapter keeps a lease index aggregate written after the lease.
- **ArchitectureTests locally.** The full evaluator cannot finish on this workstation (CS8795/CS0534 from generated-source reconstruction in other projects). With a local-only, uncommitted patch ignoring those, it reported no RP-10 finding, and a negative control (two bindings removed) reported exactly those two; the hosted gate passed and is authoritative.
- **Reviewer identity.** All verdicts are issue comments from the claimant's GitHub account; no distinct identity shows.
