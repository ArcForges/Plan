## Untested coverage

- **Wrong-user and cross-account denial: never observed.** No second account was available. Only the pipe DACL and Unix mode requirements were inspected or unit-checked, not an actual denied connection.
- **Linux and macOS runs and socket enforcement: not performed.** The Unix socket code ran only as AF_UNIX on Windows, where the owner-only directory and 0600 mode checks are skipped; Linux and macOS socket permissions, owner enforcement, `SO_PEERCRED`-class behavior and the Unix-only permission test were not exercised locally (the Unix-only permission test was expected to run in hosted CI on Linux; its execution there was not separately checked). All opt-in OS checks are Windows-only. macOS has no host and no CI.
- **The client's pipe ownership check against a foreign pipe: not tested.** A foreign pipe needs another account.
- **Peer identity is not authenticated by this task.** The library does not read the peer process or user of an accepted connection; the synchronous `(Transport, Sequence)` authorizer will have to change when the endpoint-identity task (PLT.10) adds peer and launch identity. Pipe-name squatting by another process of the same user is contained only by unguessable per-launch names (PLT.10) and the client ownership check.
- **A silent peer holds a connection slot.** One of the 8 default connection slots stays taken by a connected peer until its connection ends; this task adds no idle timeout, slot accounting by caller or fairness (PLT.13 owns bounds), so a same-user peer that connects and says nothing can occupy slots, and the other peers wait in the OS backlog (16).
- **The Named Pipe is reachable through the network namespace** (for example `\\127.0.0.1\pipe\<name>`): instances are created without the reject-remote-clients flag. The DACL limits access to the current account and the process owned no TCP listener, but the pipe is not claimed to be network-isolated.
- **Native AOT publish of this library by the claimant: not performed.** Static AOT/trim analyzers (IL2026 and IL3050 as errors) pass, and hosted CI compiles only the PRF.04 probe. A reviewer's scratch Native AOT win-x64 publish of a probe that consumed an earlier head of the library ran a generated call over a real Named Pipe; that is a reviewer observation, not committed evidence.
- **Guards with no failing test:** client compression-provider clearing (not observable through the public API), the post-start IP-address guard, and the single-listener-factory guard each survive removal without a test failure; the Unix socket owner-only, mode 0600 and never-over-an-existing-file call sites run only in the opt-in checks. Hosted gitleaks was not run locally.
- **Not in scope and not claimed:** endpoint descriptor, nonce and epoch (PLT.10), registration lease and fencing (PLT.11), routing and version refusal (PLT.12), call queues, fairness and typed overload (PLT.13), disconnect and retry semantics (PLT.14), brokered resources (PLT.15), package publication (PLT.16), restricted-launch containment (PLT.45).
