## Limits and untested coverage

- The processor is a callable that host exporters must use. It is installed in no pipeline: the repository has no OpenTelemetry or exporter dependency, and wiring one is PLT.53 and the product hosts. `Activity` span events recorded with `Activity.AddException` cannot be removed from a live span; the live activity keeps the message and stack (a test shows this) and only the copied `ScrubbedSpan` is safe to export.
- The structural audit is a reference audit exercised on synthetic secret and content types only. It examines one type's own declared members (including explicit interface method implementations), treats arrays, spans, memory, sequences, `Task<>`, `ValueTask<>`, `Lazy<>`, `Func<>`, `IEnumerable` carriers, `StringBuilder`, `TextReader` and `TextWriter` of text or bytes as text, and reports a non-`object` base type as a finding. It does not follow members transitively, does not examine explicit interface property implementations, and does not recognise unlisted carriers. `SecretRef` and `ConnectorSecretGrant` (PLT.40) were not audited by it; they rely on PLT.40's own redacted-`ToString` and no-reveal-surface tests, and the reviewer read both and judged they would pass the audit as written. Auditing them with it needs a project reference from the Observability tests to `ArcForges.Security.Secrets`, which changes hashed dependency inputs outside this task's scope. No content types exist in this repository yet.
- `sampling.head.defaultRatio` and `retention.durationsByClassAndEnvironment` are `null` under `notFixedByDesign` in the policy file: Design does not fix them. They are for PLT.50 and deployment configuration. The policy file is a mirror enforced by tests, not a runtime input.
